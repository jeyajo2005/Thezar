# 👑 TheZar - Tamil Nadu State-Level Talent & Event Platform

**TheZar** is a full-stack platform designed for organizing, hosting, and tracking Tamil Nadu state-level talent competitions, district events, participant registrations, digital entry passes, and real-time leaderboards.

---

## 🏗️ Repository Architecture

This repository is structured as a monorepo containing both the frontend client and backend API services:

```
Thezar/
├── frontend/     # React 19 + Vite + Tailwind CSS v4 frontend client
├── backend/      # Express.js + Node.js API server
└── .gitignore    # Global Git ignore rules
```

---

## ⚡ Quick Start

### 1. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 2. Backend Setup

```bash
cd backend
npm install
npm start
```

---

## 🛠️ Tech Stack

### Frontend
- **React 19** + **Vite 8**
- **Tailwind CSS v4**
- **React Router v7**
- **Lucide Icons**, **Canvas-Confetti**, **QRCode.react**

### Backend
- **Node.js** + **Express.js**
- **Cors** & **Dotenv**
